## 0. 人類裁定原文（逐字引用 `PROJECT_STATE.md` L7–L9）

1. **裁定①（公式改造）**：補貼 ＝ 每年折舊費用（車價÷年限）×（系統統計年度公務里程 ÷ **使用者輸入之該車年度總里程**），最終一次四捨五入為整數；「預估年度行駛公里數」不再參與申請計算；申請表單新增「年度總里程」輸入欄（保養比例分攤同型）。
2. **裁定②（證明選填）**：折舊證明改選填——仍可上傳（上限 5 照舊）、完成不再要求 ≥1（DEPRECIATION_ATTACHMENT_REQUIRED 退場）。
3. **連帶 (A)**：比例 >100% 擋完成（與保養一致，提示修正年度總里程）。
4. **連帶 (B)**：參數凍結退場——新版本只需車價＋年限，預估年里程與推導單價自介面退場、歷史版本唯讀保留（比照 005a 油資模型 D1(a) 處理方式）。
5. **連帶 (C)**：對帳揭露面——畫面顯示每年折舊費用＋公務里程＋輸入總里程＋比例＋金額（放寬「不顯示推導值」至每年費用層級，車價本身仍不顯示）。

### 1.1 FE-US-17 建立年度折舊申請

#### 現行原文（`userstory.md` L535–L559，逐字引用）

```
## FE-US-17 建立年度折舊申請

作為一般使用者，我希望選擇申請年度並上傳證明，以便申請年度折舊補貼。

### 驗收條件

* Given 使用者點擊「新增折舊補貼申請」
  When 進入表單
  Then 系統應提供申請年度及證明圖片欄位。

* Given 使用者選擇年度
  When 系統載入資料
  Then 應顯示該年度已完成且未作廢差旅的公務總里程。

* Given 年度公務里程由系統計算
  When 使用者查看表單
  Then 不得提供直接覆寫該數值的欄位。

* Given 同年度已有其他折舊申請
  When 使用者再次建立申請
  Then 系統應顯示提醒，但允許繼續。

* Given 草稿缺少證明
  When 使用者儲存
  Then 系統應允許保存。
```

#### 修訂後全文（提案）

```
## FE-US-17 建立年度折舊申請

作為一般使用者，我希望選擇申請年度並輸入該車年度總里程，以便申請年度折舊補貼。

### 驗收條件

* Given 使用者點擊「新增折舊補貼申請」
  When 進入表單
  Then 系統應提供申請年度、該車年度總里程及證明圖片（選填）欄位。

* Given 使用者選擇年度
  When 系統載入資料
  Then 應顯示該年度已完成且未作廢差旅的公務總里程。

* Given 年度公務里程由系統計算
  When 使用者查看表單
  Then 不得提供直接覆寫該數值的欄位。

* Given 年度總里程為使用者自行申報之數值
  When 使用者填寫表單
  Then 系統應提供可輸入欄位，並與系統計算之年度公務里程明確區分呈現。

* Given 同年度已有其他折舊申請
  When 使用者再次建立申請
  Then 系統應顯示提醒，但允許繼續。

* Given 草稿缺少證明或尚未填寫年度總里程
  When 使用者儲存
  Then 系統應允許保存。
```

#### 逐條來源標記與理由

| 修訂後 AC | 標記 | 理由 |

作為一般使用者，我希望查看年度公務里程、折舊單價與補貼金額，以便確認申請結果。

### 驗收條件

  Then 系統可以顯示每公里單價，但不得顯示完整內部推導過程。

#### 修訂後全文（提案）

```
## FE-US-18 預覽年度折舊補貼

作為一般使用者，我希望查看每年折舊費用、年度公務里程、年度總里程、公務比例與補貼金額，以便確認申請結果。

### 驗收條件

* Given 申請年度存在有效折舊參數
  When 系統載入預覽
  Then 應顯示每年折舊費用。

* Given 系統取得年度公務里程且使用者已輸入年度總里程
  When 計算預覽
  Then 應顯示公務比例。

* Given 每年折舊費用、年度公務里程及年度總里程均有效
  When 計算預覽
  Then 應顯示四捨五入後的年度補貼金額。

* Given 公務比例大於 100%
  When 系統計算
  Then 應顯示錯誤並阻止完成申請，並提示檢查年度總里程。

* Given 一般使用者查看折舊申請
  When 顯示計算資訊
  Then 系統可以顯示每年折舊費用，但不得顯示車價及折舊年限。

* Given 使用者尚未輸入年度總里程
  When 系統載入預覽
  Then 應顯示無法計算之狀態，不得顯示金額 0 元。

* Given 申請年度沒有有效折舊參數
  When 使用者嘗試完成
  Then 系統應提示聯絡管理員設定參數。
```

#### 逐條來源標記與理由

| 修訂後 AC | 標記 | 理由 |
|---|---|---|
| 第 1 條（單價 → 每年折舊費用） | 【裁定】 | 裁定 (C)「畫面顯示每年折舊費用」；裁定①「預估年里程不再參與申請計算」使每公里單價不再存在於新模型 |
| 第 2 條（顯示公務比例） | 【裁定】 | 裁定 (C) 明列「比例」 |
| 第 3 條（金額顯示，來源改三值） | 【裁定】 | 裁定① 公式改造 |
| 第 4 條（>100% 顯錯並擋完成） | 【裁定】 | 連帶 (A)；措辭比照 FE-US-14 第 4 條 |
| 第 5 條（揭露面：可顯示每年費用、不得顯示車價與年限） | 【裁定】＋【擴張】 | 「可顯示每年費用、車價不顯示」為裁定 (C) 原文；**「折舊年限亦不得顯示」為擴張**——每年費用 × 年限即還原車價，僅遮蔽車價無法達成裁定意圖（見 **Q6**） |
| 第 6 條（未輸入總里程時不顯示 0 元） | 【建議】 | 沿 PHASE-006／PHASE-007 既有「calculable=false 不渲染 0 元」慣例，避免 0 元被誤讀為計算結果 |
| 第 7 條 | 逐字保留 | 不受影響 |

#### 影響

- **刪減既有 AC**：原第 1 條「應顯示折舊每公里補助單價」與第 3 條「可以顯示每公里單價」之單價語意退場。**屬須人類批准項**（改變使用者可見行為＋刪減 AC）。
- 揭露面放寬（每年折舊費用可見）屬使用者可見行為變更，**須人類批准**。
