## 本次 Gate 範圍聲明（重要，先看這段）

**「Mock Gate」在本專案是沿用 PHASE-008 的名稱慣例，不是「假資料 / stub」的意思。** 實查 PHASE-008 先例：Mock Gate 走 **dev 拓撲**（`localhost:5173` 前端 ＋ `localhost:3000` 後端 ＋ 真實 PostgreSQL `t1-pg`），整合 Gate 才走**容器版**（`localhost:8080`）。本次沿用，不合併。

- **本場涵蓋**：真實前端 ＋ 真實後端 ＋ 真實資料庫 ＋ 合成資料。您點的每一個按鈕都會真的寫進資料庫、真的產生 PDF。

- **E2E 自動化測試（44 條）本 Phase 尚未實跑**——已知缺口，由 T17／終審負責補跑，不在本場檢核範圍。本場為**人眼目視**，兩者不互相取代。

### 定案①　「重複計入」提醒文案的逐字用詞　**【Spec 明文指定由本 Gate 定案】**

- **現值**（三型詳情頁逐字相同）：
  > 本申請仍為已完成狀態。若未作廢，本申請與修正版將同時計入里程與金額統計；如需避免重複計入，請於本頁作廢本申請。
- **現場**：段落 C 步驟 C-4。
- **背景**：您在 Spec Gate 批准 D15=(a)「建立修正版**不**自動作廢原申請」，**批准前提就是這則前端強提示**。三點語意不可縮減：①原申請仍為已完成 ②不作廢則兩筆都計入統計 ③作廢入口就在本頁。
- **改字的影響面（spec-writer 實查）**：**6 處逐字常數**（三型頁生產碼各一 ＋ 三個測試檔各一份對照常數）＋ **17 條斷言**（10 條綁常數會自動跟隨、**7 條硬編子字串「同時計入里程與金額統計」須同步改**）。改字須走 Gate 反饋流程：Spec 修訂 → implementer TDD → 複審。
- **選項**：(a) 照現值定案（推薦——三點語意完整、已有測試釘樁）／(b) 提出改寫版本（三點語意不得縮減）。

### 定案③　**必問**：已作廢頁面看不到「整筆金額」，但作廢版 PDF 裡有金額　**【本 Phase 唯一使用者可見落差；reviewer AR-2 指定人工走查必問】**

- **現況（spec-writer 實查證實）**：後端只對 `COMPLETED` 投影「完成時快照」，所以**已作廢的詳情頁不會顯示「計算依據（完成時快照）」整個區塊**（含「整筆金額」「油資單價」「ETC 單價」「計算時間」）；但**逐段金額仍然顯示**，且**作廢版 PDF／列印版金額完整呈現**。
- **後果**：使用者在畫面上看不到這筆的總金額，下載 PDF 卻看得到——同一筆資料兩種呈現。
- **現場**：段落 A 步驟 A-5（畫面）對照段落 B 步驟 B-1（列印版）。
- **選項**：
  - **(a) 接受現況**（成本 0；理由：作廢＝不再計入統計，畫面刻意弱化金額；PDF 是歷史文件必須完整）
  - **(b) 在已作廢頁補一個「作廢當時金額」欄位**（屬**使用者可見行為擴充**，須 Spec 修訂 ＋ 新 AC ＋ implementer ＋ 複審；三型頁 ＋ 後端 DTO 投影都要動）
  - **(c) 其他呈現方式（請描述）**
