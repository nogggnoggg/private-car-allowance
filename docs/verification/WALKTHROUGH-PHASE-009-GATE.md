## 段落 1｜報表與容器 PDF 字形（素材 A、M）

1. 開 <http://localhost:8080> 登入 `e2eadmin`。
2. 首頁申請列表找到「整合 Gate 走查素材（A-報表檢視）」→ 點入詳情。
3. 報表區塊點「檢視列印版」→ 新分頁應為完整報表版面，**中文全部正常顯示（無方塊字）**。
4. 回詳情頁點「下載 PDF」→ 開啟 PDF：**繁體中文字形正常、版面與列印版一致、報表編號 TRV-202607-xxxx 格式**。

## 段落 2｜作廢全流程（素材 B）——統計下降＋作廢版 PDF

1. 先開「公務里程統計」頁，期間選 2026-07-01～2026-07-31：應為 **435.00 公里／3 筆**（記下數字）。
2. 進素材 B 詳情 → 點「作廢」→ 對話框輸入原因（例：「整合 Gate 走查作廢測試」）→ 確認。
3. 詳情頁應變為：狀態「已作廢」、唯讀、出現「作廢資訊」四項（原因／操作者／時間／**作廢當時金額**——Mock Gate 定案③）。

6. 點「檢視列印版」：同樣有作廢標示。

## 段落 3｜修正版全流程（素材 C）

1. 進素材 C 詳情 → 點「建立修正版」→ 確認。
2. 應跳轉到新草稿：欄位與兩段行程、附件皆已複製；頁面有「本筆修正自…」版本關係區塊，並顯示重複計入提醒文案。
