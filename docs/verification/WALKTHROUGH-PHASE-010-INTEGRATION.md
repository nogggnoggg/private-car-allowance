## 這次要看什麼（30 秒版）

Mock Gate 看過的稽核頁，這次在**正式容器拓撲**裡再走一遍重點：您親手做一次管理操作與一次作廢，然後在稽核頁查到它們；順便看拒刪與無權限的真實畫面。約 8 分鐘。

## 帳號（全合成）

- 管理員：`e2eadmin / E2eAdmin@456!`
- 一般使用者：`gateuser1 / GateUser@2026!`（名下已有一筆**已完成差旅**供作廢）

## Step-by-step

### A. 親手產生兩筆稽核（4 分鐘）

1. 開 `http://localhost:8080`，以**管理員**登入。
2. 【管理操作】管理員頁面建立一個新使用者（帳號/顯示名稱隨意，密碼自訂合成值）→ 成功。
3. 登出，改以 **gateuser1** 登入 → 我的申請列表應有一筆「已完成」差旅 → 進入詳情 → **作廢**，原因輸入一句中文（例：「整合走查測試作廢」）→ 成功。
4. 登出，回**管理員** → 稽核紀錄頁 → 應看到：您剛建立的使用者（「新增使用者」）與剛才的作廢（「申請作廢」，操作者＝gateuser1，原因逐字可見、值中文、無內部編號）。

### B. 拒刪真實畫面（2 分鐘）

5. 管理員 → 使用者管理 → 對 **gateuser1** 嘗試刪除 → 應顯示「**此帳號已有資料，無法刪除，請改用停用**」（非系統錯誤）。（此帳號名下有申請與油耗版本——正是 D5 補齊的守門。）

### C. 權限拒絕真實畫面（1 分鐘）

6. 以 **gateuser1** 直接輸入網址 `http://localhost:8080/admin/audit-logs` → 無權限訊息、零稽核內容；首頁亦無稽核入口。

### D. 篩選抽驗（1 分鐘）

7. 管理員稽核頁以「操作類型＝申請作廢」＋今天日期篩選 → 恰您那筆作廢在列。

## 揭露事項

1. 容器環境時區為 UTC——畫面時間依**您瀏覽器**時區顯示（台灣時間）、日期篩選以台灣日為準：兩者一致（MG-2/SF-3 已裁定架構）。
2. 素材由大總管以 API 預播（參數版本/油耗/該筆已完成差旅）；您在 A 段親手產生的兩筆才是本 Gate 的端到端證明主體。
3. E2E 套件執行後 dev/container DB 會留下合成殘留（不可刪之稽核列）——屬設計，Phase 邊界重置清理。
