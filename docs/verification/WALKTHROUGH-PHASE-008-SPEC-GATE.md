## 這次要決定什麼（30 秒版）

PHASE-008 做「報表」：已完成的申請可以①拿到一個唯一報表編號②在瀏覽器看列印版③下載正式 PDF。您要批准的是：**16 個設計決策（D1~D16，每個都附推薦）＋10 個高風險 Task 的事前批准**。全部照推薦的話，回一句「照推薦」即可。

1. **（2 分鐘）讀 Spec §0.1 範圍表**——確認做什麼/不做什麼符合您的預期（修正版/作廢屬 PHASE-009）。
2. **（5 分鐘）掃 D1~D16 決策表**（Spec §16；下方有白話摘要）——每條有推薦；不同意哪條就點名哪條。
3. **（1 分鐘）看 High Task 清單**（10 項，下方列出）——批准即為事前批准，之後不再逐項請示。
4. **（重點 2 條，請務必親自過目）**：
   - **D4 附帶批准②**：容器內 Chromium 以 `--no-sandbox` 執行——**這是安全取捨**。理由：渲染的 HTML 100% 由後端自己產生、零腳本、零外部資源（有結構性測試守門），攻擊面已封閉。但關閉 sandbox 仍是防禦層減一，需您明示接受。
   - **D9**：管理員可代使用者產生報表（沿既有代操作語意）——授權面選擇。
5. **（可選）兩項資訊補充**：①Zeabur 方案的映像/記憶體上限（Chromium 使映像 +350~450MB、渲染尖峰 +150~300MB）②CI 硬體效能（影響 PDF 10 秒門檻測試）。不知道也可以先進行，遇到再調。
6. 在對話中回覆裁定（AskUserQuestion 已備妥三問）。
